# E-Commerce Sales Analysis

## Project Overview
This project analyzes e-commerce order data to understand sales performance,
product revenue, customer behavior, and order status trends.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Dataset
The dataset contains e-commerce order information, including:
- Order date
- Customer ID
- Product and category
- Quantity and unit price
- Discount
- Region
- Payment method
- Order status

## Project Objectives
- Analyze revenue trends over time
- Identify top-performing products and categories
- Compare regional sales performance
- Analyze customer retention and segmentation
- Investigate product returns and cancellations

## Key Findings
- High-value customers represent 25% of customers and contribute 54.64% of delivered revenue.
- Customer retention rate is 82.83%, while churn rate is 17.17%.
- Delivered revenue declined by 3.41% from 2024 to 2025.
- Delivered order volume declined by 1.43%, and average revenue per order declined by 2.00%.
- Webcam has the highest product return rate at 7.09%.
- Bluetooth Speaker has the highest product cancellation rate at 5.94%.
- Video category has the highest return rate at 7.09%.
- Audio category has the highest cancellation rate at 5.50%.
